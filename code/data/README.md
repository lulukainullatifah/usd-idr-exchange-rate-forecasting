# Data

The raw data used in this project is **not included** in this repository
due to file size and licensing considerations.

**Data Source:** Bank Indonesia — Official Transaction Rate
**URL:** https://www.bi.go.id/id/statistik/informasi-kurs/transaksi-bi/Default.aspx
**Period:** January 4, 2021 – December 31, 2024
**Observations:** 979 data points
**Format:** The script expects a dataframe `data2` with columns `Tanggal` (Date) and `Kurs` (numeric)
